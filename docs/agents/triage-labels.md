# Triage Labels

Map canonical triage roles to this repo’s GitHub labels.

| Canonical role    | Tracker label     | Meaning                                        |
| ----------------- | ----------------- | ---------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate the issue         |
| `needs-info`      | `needs-info`      | Waiting on the reporter for more information   |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an unattended agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation                  |
| `wontfix`         | `wontfix`         | Will not be actioned                           |

When a skill mentions a role, use the corresponding tracker label.
Edit the tracker-label column to change the vocabulary.
